# خرائط دليل الزائرين

خرائط محافظات العراق (PMTiles من OpenStreetMap عبر Protomaps) وشبكات شوارعها للطريق بدون إنترنت، يقرأها تطبيق دليل الزائرين.

- `maps.json`: قائمة المحافظات وروابط ملفاتها.
- الملفات نفسها في صفحة Releases.

البيانات © مساهمو OpenStreetMap، رخصة ODbL. حدود المحافظات من geoBoundaries.
